# Contributing

Thanks for improving this project.

## Workflow

1. Create a branch with a clear name, such as `feat/tutor-history` or `fix/progress-sync`.
2. Keep changes focused and small enough to review.
3. Update docs when auth, API, tutor, or learning behavior changes.
4. Open a pull request using the template.
5. Include screenshots or short demos for student, teacher, or admin UI changes.

## Quality Checklist

- Client and server install cleanly.
- Relevant build or health checks pass.
- No secrets, `.env` files, generated outputs, or student data are committed.
- The PR explains the learning or admin impact.
